Bomberman-Hero-Quest-3-VR-Standalone
A standalone port of PC Bomberman Hero Recomp that runs natively on the MetaQuest 3.

FEATURES

-PLUG AND PLAY-

Simply provide your copy of the 1.0 North American version of the game in the main menu and start playing! This project will automatically load assets from the provided copy, so there is no need to go through a separate extraction step or build the game yourself. 

-KNOWN BUGS-

When screen recording on the MetaQuest headset, the resolution will drop to keep the framerate high.  When you stop recording, the resolution will revert back to normal. this is a MetaQuest bug and I am working on fixing.
